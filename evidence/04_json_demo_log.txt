=======================================================
  Demo: JSON Formatting & Repair
=======================================================

[Valid JSON] PASS
  Input:  {"name": "Alice", "age": 30}
  Output: {"name": "Alice", "age": 30}
  🔧 JSON đã được sửa thành công

[Markdown fences] FIX
  Input:  ```json
{"name": "Bob"}
```
  Output: {
  "name": "Bob"
}
  🔧 JSON đã được sửa thành công

[Single quotes] FIX
  Input:  {'name': 'Charlie', 'score': 95}
  Output: {
  "name": "Charlie",
  "score": 95
}
  🔧 JSON đã được sửa thành công

[Trailing comma] FIX
  Input:  {"key": "value",}
  Output: {
  "key": "value"
}

[Truly invalid] FIX
  Input:  This is not JSON at all: ??? {]
  Output: {
  "error": "Không thể phân tích JSON",
  "raw": "This is not JSON at all: ??? {]"
}
